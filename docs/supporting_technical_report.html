Architecture

A four-stage, deterministic prompt chain (no agent loop, no retrieval) wraps a single-paper input: (1) paragraph-respecting chunking (~700 words/chunk), (2) per-chunk relevance tagging, (3) per-chunk quoted-evidence extraction, (4) whole-paper synthesis into Problem/Method/Results/Limitations, and (5) a hallucination-check pass that re-verifies every synthesized sentence against the numbered source chunks before the user sees it. The chain is exposed through a Streamlit UI that accepts pasted text or an uploaded PDF.

Tools and models used

Anthropic Claude Sonnet 5, called via the Anthropic Python SDK. Streamlit for the UI. pypdf for PDF text extraction. All four prompts run at temperature 0 except synthesis (0.2), chosen to keep tagging/extraction/verification deterministic while allowing slightly more natural phrasing in the final synthesized summary.

Prompt design

Evidence is extracted (quote + paraphrase) before synthesis, not after, so every claim in the final summary is traceable to source text by construction rather than by a single end-of-pipeline check. The hallucination-check prompt (P4) went through 3 iterations: v1 (free text, unparseable in 10/10 runs) → v2 (JSON schema, but unverifiable "supported" claims, missed 2/5 injected hallucinations) → v3 (numbered source chunks + required supporting_chunk_ids, caught 5/5 injected hallucinations). Full prompt text and iteration log are in the project repository (prompts/, docs/prompt_iteration_log.md).

Limitations

  1. No gate rejects non-paper input before the chain runs (it will still try to "summarise" e.g. a shopping list).
  2. Summary language mirrors the input paper's language instead of always producing English.
  3. The hallucination check verifies per-sentence support, not cross-section numeric consistency — an abstract's number and a contradicting results-section number can each individually pass the check.
  4. Implicit limitations stated outside a heading literally called "Limitations" (e.g. inside a Conclusion) are sometimes missed by the zero-shot relevance tagger.
